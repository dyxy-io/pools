# Choosing a pool

The same pair often exists on several protocols and fee tiers. The pool explorer lists them side by side.

| Column | Meaning |
| --- | --- |
| Pool | Tokens, protocol, fee tier |
| Network | Where the pool lives |
| TVL | Total value locked |
| 24h volume | Trading volume over the last day |
| 24h fees | Fees earned by LPs over the last day |
| APR | Estimated yearly return from fees and rewards, based on recent activity |

## What to compare

| Factor | Why it matters |
| --- | --- |
| Fee tier | Higher tiers earn more per trade but attract less volume |
| Volume ÷ TVL | Higher means each dollar of liquidity earns more |
| Rewards | Emissions raise APR, but their value follows the reward token's price |
| Network | Gas for adding, adjusting and claiming |

## Rough fee APR

```
fee APR ≈ (24h fees ÷ TVL) × 365
```

For a concentrated position, the user's own APR depends on the chosen range: narrower ranges earn a larger share while in range.

APR is an estimate from recent activity. It changes daily and is never guaranteed.
